# RFM Müştəri Seqmentasiyası

Google Sheets-də aparılmış qısa RFM analizidir. Müştərilər son alış vaxtı (**Recency**), alış sayı (**Frequency**) və xərclədiyi məbləğə (**Monetary**) əsasən qiymətləndirilib.

## Əsas nəticələr

42 müştərinin:

* **43%-i** diqqət tələb edir
* **26%-i** itirilmiş müştəridir
* **17%-i** risk altındadır
* **14%-i** yeni, loyal və champion müştərilərdir

Nəticələr müştəri saxlama və geri qazanma kampaniyalarının prioritetləşdirilməsinin vacibliyini göstərir.
